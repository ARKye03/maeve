# Maeve Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Desktop app (iced) that scrapes 2+ Mercado Libre UY / TEMU product URLs, computes landed cost in UYU, runs a Gemini advocates-plus-judge debate, and shows a verdict with verifiable stats and local history.

**Architecture:** Rust iced 0.14 app on tokio. A long-lived Python sidecar (original Scrapling, run via `uv`) does scraping over JSON lines on stdin/stdout. Pure-Rust domain core (cost engine, stat table) sits under an async pipeline (scrape → advocates → judge) that streams progress events into the UI. History and settings live in an embedded `turso` DB; the Gemini key lives in the macOS Keychain.

**Tech Stack:** Rust 2024, `iced` 0.14 (`tokio`, `image`, `canvas` features), `tokio`, `reqwest` (json, rustls), `serde`/`serde_json`, `turso` 0.8, `keyring` (apple-native), `arboard`, `jiff`, `base64`, `thiserror`, `url`, `dirs`, `futures`; dev: `wiremock`, `tempfile`. Python 3.11+ via `uv`, `scrapling[fetchers]`, `pytest`.

**Spec:** `docs/superpowers/specs/2026-11-12-maeve-design.md`. Read it first; this plan does not repeat its rationale.

## Global Constraints

- Rust edition 2024, `iced = "0.14"`. Follow the `rust-best-practices` and `rust-async-patterns` skills.
- Comment sparingly: only non-obvious "why". Docs short, bullets.
- Scraper is the original Python Scrapling (D4Vinci/Scrapling). No Rust ports.
- Sites: Mercado Libre Uruguay (`mercadolibre.com.uy`, IDs `MLU…`) and TEMU only.
- Money is integer minor units (`i64` cents). Display currency UYU: `$1.647`; USD shown as `U$S 49`. Uruguayan format: `.` thousands, `,` decimals.
- Cost defaults: IVA `22%`, Régimen Simplificado `60%`, ML free-shipping threshold `$1.000` UYU, TEMU shipping default `$0`. Tax base = product + shipping. ML prices are IVA-inclusive (no tax added).
- Every displayed number traces to scraped/pasted data, or is visibly marked (estimated tax, converted currency, AI-parsed numeric).
- Gemini free tier: all calls go through one client-side rate limiter; default `10` requests/minute, configurable.
- Gemini key only in Keychain (service `maeve`, user `gemini_api_key`); never in DB, files or logs.
- UI strings in ES and EN; default ES. Gemini output follows UI language.
- Theme tokens exactly as in the spec's Theme table. Remove the reference theme CSS in Task 15.
- UI tasks verify visually: run `scripts/snap.sh`, `Read` the PNGs, compare against Layout A (spec "UI" section; local mockup `.superpowers/brainstorm/*/content/layout.html` if present), fix, re-snap until it looks right in light and dark.

## Review Focus

1. **Uruguayan number formats** (`$ 1.234`, `U$S 49,90`, `US$ 1.299,00`, `$1.234,5`): must parse to exact cents; a `.` is never a decimal point in UYU strings. Test in Task 4.
2. **Fewer than 2 usable products after scraping failures**: pipeline must stop before Gemini with a clear "need at least 2 products" error, not call the judge with one. Test in Task 9.
3. **Gemini returns malformed or out-of-range JSON** (winner index ≥ n, scores length ≠ n, spec_key not in that product's specs): validated, retried once, then a readable error; never render a hallucinated spec value. Tests in Tasks 7 and 8.
4. **Sidecar unavailable** (`uv` missing, Scrapling browsers not installed, process crashes mid-request): each pending item fails with `ScrapeErrorKind::SidecarUnavailable` and a message telling the user what to install; no hang. Test in Task 5.
5. **Missing/invalid Gemini key** (none in Keychain, 401/403): Compare shows "set your Gemini key in Settings" before scraping starts; 401/403 maps to `LlmError::Auth`, not retried. Tests in Tasks 6 and 9.
